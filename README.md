# La-María

Sitio web Front-End para una pastelería artesanal de Tehuacán, Puebla.

## Tecnología

HTML, CSS y JavaScript nativos. No requiere instalar dependencias ni compilar.

## Ejecución

Abre `index.html` directamente en un navegador. Los archivos de estilo y JavaScript se cargan desde rutas locales.

## Organización

- `docs/`: plan y documentación del proyecto.
- `public/images/`: imágenes de productos, promociones y galería.
- `src/components/`: elementos reutilizables de la interfaz.
- `src/data/`: productos, promociones y datos de contacto del negocio.
- `src/sections/`: secciones principales del sitio.
- `src/styles/`: estilos globales y responsivos.
- `src/utils/`: funciones compartidas.
