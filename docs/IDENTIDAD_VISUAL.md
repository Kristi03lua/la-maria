# Identidad visual de La-María

## Dirección

Una identidad cálida, artesanal y elegante, con composición limpia y suficiente espacio en blanco. El lila identifica la marca; el verde se reserva para acentos y acciones. Evitar fondos saturados y adornos que resten protagonismo a los productos.

## Colores

| Token CSS | Color | Uso |
| --- | --- | --- |
| `--color-primary` | `#6A5492` | Marca, títulos y elementos principales |
| `--color-accent` | `#07AE8B` | Acentos y llamadas a la acción |
| `--color-accent-ink` | `#006B54` | Texto pequeño sobre fondo claro |
| `--color-ink` | `#343434` | Texto general |
| `--color-background` | `#FFFFFF` | Fondo principal |
| `--color-surface` | `#F5F5F5` | Superficies secundarias |
| `--color-rule` | `#E8E5EC` | Separadores discretos |

## Tipografía

- **Playfair Display:** marca y encabezados de sección.
- **Inter:** párrafos, navegación, precios, botones y controles.
- Mantener tamaños legibles y jerarquías claras; no usar mayúsculas sostenidas ni espaciado negativo.

## Composición adaptable

- Contenido centrado con un ancho máximo de `72rem` y márgenes laterales consistentes.
- Encabezados con ancho de línea controlado para facilitar la lectura.
- En pantallas de hasta `480px`, reducir el tamaño del título, estrechar los márgenes laterales y apilar la identificación del encabezado.
- Mantener objetivos táctiles amplios y evitar que las etiquetas o títulos desborden su contenedor.

## Imágenes y accesibilidad

- Usar fotografías claras de productos reales, con recorte coherente y texto alternativo descriptivo.
- Preferir WebP; respetar los límites de peso y dimensiones definidos en `LA-MARIAA.txt`.
- Mantener contraste suficiente entre texto y fondo, y estados de foco visibles en los controles interactivos.
- Reservar el verde de marca claro para detalles; usar el tono oscuro para texto sobre blanco.
